Hello! I'm Sombre and I always thought to myself, I want my banner to extend more to my profile and give my account a little more style. Well I made that possible with this BetterDiscord Plugin which allows users like you to find any image or GIF on the web and copy it (Right Click - Copy Image Address) and set it as a full spread background for your account!

Requires BetterDiscord Latest Version
Requires this plugin, duh!

You can change the image by going to Settings - Plugins - Profile Background and click the Gear Icon and Paste an Image or GIF Address then Save and click done.
